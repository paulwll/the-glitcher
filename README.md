# The Glitcher

A small terminal-based RPG written in C.

This is a personal project to explore C programming, Unix system calls, terminal manipulation, and the fundamentals of 2D game development.

## Current features

- Character creation
- ASCII map rendering
- Real-time WASD movement
- Terminal input handling using termios
- Typewriter-style text animations

## Planned features

- Map loading from external files
- Terrain and collision detection
- Multiple environments
- NPCs and interactions

## Status

Early development — currently a playable movement prototype.

Built from scratch as a learning project.
